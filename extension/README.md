# MemoCat 浏览器扩展

MemoCat Chrome / Edge Manifest V3 浏览器对话归档扩展。

- **项目主页**：https://memocat.qiwihui.com/
- **源码仓库**：https://github.com/qiwihui/MemoCat

## 安装

1. 在项目根目录执行 `npm run build:extension`（需要 Node.js 24+）。
2. 打开 Chrome 或 Edge 的扩展管理页（`chrome://extensions` / `edge://extensions`），开启「开发者模式」。
3. 选择「加载已解压的扩展程序」，选中项目里的 `dist/memocat-extension` 目录（也可直接加载 `extension` 目录）。
4. 首次安装会打开扩展设置页。默认采用手动保存，可按需开启自动保存。
5. 刷新此前已打开的 AI 聊天标签页，点击页面悬浮胶囊的「保存此对话」或扩展工具栏弹出面板的「保存当前对话」即可归档。

打包产物为 `dist/memocat-extension.zip`（ZIP 为未签名归档包，解压后可按上述开发者模式步骤加载）。

## 已实现功能

- **9 大 AI 平台 DOM 采集适配**：`ChatGPT`、`Claude`、`Gemini`、`DeepSeek`、`腾讯元宝`、`豆包`、`Kimi`、`千问`、`Grok`（含 `x.com/i/grok`）。
- **手动与自动保存**：页面 `MutationObserver` + 防抖监听，在检测到生成中状态时延后自动保存；尚无稳定会话 URL 的新对话仅支持手动保存。
- **三端扩展界面**：页面可拖拽折叠悬浮胶囊与右侧抽屉栏（`sidebar.html`）、工具栏弹出面板（`popup.html`）、完整双栏资料工作台（`library.html`），支持浅色 / 深色 / 跟随系统三态主题。
- **局部窗口增量合并**：基于稳定消息 ID 与精确文本游标合并更新；网页虚拟列表卸载早期历史节点时不会删除或覆盖本地已保存消息。
- **本地 IndexedDB 资料库**：支持标题/正文全文搜索、平台胶囊筛选、按 UTC 保存日期筛选、分页阅读、修改标题、重新采集、原网址回跳与删除抑制。
- **备份与导出**：支持单会话复制为 Prompt、单会话 Markdown/JSON 导出、全库 JSON 备份及原子校验后的增量合并导入。
- **可选同步至本机 MemoCat 应用**：通过 `http://127.0.0.1` 自动配对指定扩展 ID 与 256 位随机连接密钥；支持更新、删除、断线重试、重启恢复，并通过单调序列号与 `changeId` CAS 确认防止旧回执误删或旧写覆盖。

## 与本机应用连接

1. 运行 MemoCat 桌面版或本机网页服务（默认端口 `http://127.0.0.1:3792`）。
2. 在扩展「采集与桌面同步」（或弹出面板）点击「一键连接 MemoCat 并同步」。
3. 扩展会自动探测本机端口并完成扩展 ID 与 256 位连接密钥配对，立即将本地会话队列同步到 MemoCat SQLite 资料库。
4. 同步成功后，可在桌面端 **会话工作台** 按网页来源筛选查看，并在 **数据管道** 的 MCP 客户端来源白名单中单独授权。

首次连接或更换接收地址/密钥时会重新排入全部本地会话；之后按变更队列增量同步，后台 `alarms` 每分钟重试一次未确认变更。若本地应用重置了连接密钥或重新加载扩展导致 ID 变化，在扩展中再次点击连接即可重新配对。

## 行为与边界

- 保存的是页面**当前已加载的文字内容**。不会调用聊天平台私有接口批量拉取未展开的历史，也不自动下载图片、附件、音频或视频。
- 只采集普通问答文本，不保证特殊画布、复杂工具卡片或分支树的完整语义；思考/工具过程仅对已知标记排除。
- 当网站不提供稳定消息 ID 时按角色与文字精确匹配；编辑、重生成或虚拟列表出现重复文本时可能保留额外版本。
- 新对话尚无稳定 URL 时，手动保存使用页面临时 `draft` ID；后续页面获得正式 URL 后可能作为新会话记录保存。
- 每段对话上限 `8 MiB` / `10,000` 条消息，单条文字上限 `500,000` 字符，导入 JSON 备份上限 `64 MiB`。
- 权限与来源隔离：默认不自动采集，不发遥测，不使用 `<all_urls>`；`web_accessible_resources` 仅对 `manifest.json` 声明的 9 个 AI 平台域名开放（用于加载侧边栏与图标资源）；资料读写/导入/删除/同步控制消息仅接受本扩展正式页面来源。
- 采用基于本机 `http://127.0.0.1` 的独立配对与队列同步协议，不包含账号体系、云同步或遥测；本地 IndexedDB 与导出 JSON 备份均包含明文聊天内容，无应用层静态加密。

## 开发与测试

```bash
# 单元与同步协议集成测试
npm test

# 构建解压目录与 ZIP 包
npm run build:extension

# 浏览器真实 MV3 端到端测试（隔离临时目录，不接触个人浏览数据与登录账号）
npm run test:extension:browser
```

`test:extension:browser` 默认调用 macOS `/Applications/Microsoft Edge.app` 创建隔离临时配置目录加载扩展，并通过 CDP 将平台请求拦截为本地合成 HTML 夹具，验证 9 大平台采集、权限隔离、局部窗口合并、重启持久化、增量备份恢复、桌面同步、MCP 召回与窄屏布局。可通过 `MEMO_BROWSER_BINARY=/path/to/chromium` 指定其他支持 `--load-extension` 的 Chromium 内核浏览器。
