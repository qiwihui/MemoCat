Support & FAQ

MemoCat v0.5.0 · For bug reports or questions, please open an issue on GitHub Issues and include your macOS version and run mode (Desktop / Web / Extension).

Quick Start

  1. Authorize Local Folders: Open "Data Pipeline" in MemoCat, expand Codex (~/.codex), Claude Code (~/.claude/projects), Grok Bot, or Antigravity, click "Choose Folder…" to grant read-only access, enable the toggle, and run "Sync Now".
  2. Pair Browser Extension: Load dist/memocat-extension in Chrome/Edge, save a conversation via the floating button (or turn on Auto-save), and click "Connect & Sync" under extension Connections.
  3. Configure MCP Clients: Under "Data Pipeline → Local MCP Endpoints", copy the configuration for Codex, Claude Code, or another local HTTP MCP client, choose allowed sources, and click "Test Handshake" to verify 127.0.0.1:3792.

Frequently Asked Questions

How do I pick hidden folders like ~/.codex in the macOS sandboxed desktop app?

Click "Choose Folder…" inside any source card under Data Pipeline. MemoCat configures the open dialog with showHiddenFiles enabled. If hidden folders still do not appear in macOS Finder view, press ⌘ + Shift + . to toggle hidden files or press ⌘ + Shift + G to enter the folder path directly. Permissions persist across restarts via Security-Scoped Bookmarks.

What if extension sync fails after rotating the pairing token or reloading the unpacked extension?

Ensure MemoCat Desktop or the local web server is running on port 3792. If you rotated the secret token in the desktop app or reloaded the unpacked extension (changing its 32-char ID), simply click "Connect & Sync" again in the extension. It automatically re-pairs over 127.0.0.1 without losing pending outbox changes.

Why are unexpanded scroll history or remote web images missing from extension captures?

The browser extension only reads text messages currently rendered in the active page DOM. It does not scrape private platform APIs or download remote images, audio, or video. For long virtualized threads, messages observed once are retained via partial-window reconciliation and will not be overwritten when older DOM nodes scroll out of view.

How can I restrict which sources an AI tool can read over MCP?

In "Data Pipeline → Local MCP Endpoints", expand the client card (such as Codex), uncheck "All saved sources", select only the specific sources you want to allow, and save the scope. When zero sources are selected, the MCP server rejects both recall and list_conversations for that endpoint.

Where is my archive stored, and how do I back it up or erase it?

Local web mode stores memo.sqlite under ~/.memocat/<userId>/ (or MEMO_DATA_DIR); Desktop mode uses Electron's userData/library/memo.sqlite. Check Settings → Local Data Directory for the active path. Quit MemoCat cleanly before copying the directory to back it up, or delete the directory to remove all local data. Extension backups can be exported as JSON or cleared under Extension Settings.
