Core Architecture

Structured Reading, Hybrid Recall & Delivery Auditing

Powered by Node.js 24 built-in node:sqlite and HTTP modules. Desktop and local web interfaces share the exact same indexing, ranking, and delivery engine.

Two-Pane Conversation Workbench

Filter threads by source pills or date, and read clean user/assistant chat bubbles with syntax-ready code blocks and question outline navigation.

  • Quick Search: ⌘K across titles, message text, and code
  • Keyboard Flow: ↑ / ↓ thread switching + right-edge question outline
  • Export & Reuse: Copy as structured XML prompt, Markdown, or .md file
  • Responsive Shell: Compacts down to quarter-screen width (< 600px)

Hybrid Search & Region Budget

Combines SQLite WAL + FTS5 trigram indexing with turn-level BM25 neighborhood smoothing to assemble high-signal context within token limits.

  • Tokenization: CJK overlapping 2-grams + alphanumeric tokens
  • Weights: User turn 2.5 vs assistant 1.0; primary 1.0 vs keywords 0.72
  • Region Smoothing: 5-neighbor kernel expands and merges adjacent matches
  • Hard Cap: Up to 8 regions and ~9,600 tokens per recall call

Context Deduplication & Audit Trail

Tracks each AI conversation via process_id and a 3-state delivery table so repeated recalls do not resend already delivered full units.

  • Caller Binding: Issues process_id scoped to each MCP caller path
  • Delivery States: prepared, committed, and abandoned
  • Deduplication: Excludes committed full unitIds; retains truncated parts
  • Audit Stream: Inspect exact text snapshots delivered in past recalls
Cross-AI Interop

Local Streamable HTTP MCP Endpoints

While running, MemoCat exposes stateless JSON-RPC 2.0 POST endpoints on http://127.0.0.1:3792 with per-client switches and source whitelists.

recall Memory Retrieval

Accepts query, up to 8 alternatives, date range from/to, sources filter, and process_id. Triggers an on-demand sync before returning attributed segments.

list_conversations Date Inventory

Lists archived conversation metadata across up to 31 days in the host timezone, restricted by the calling client's source whitelist.

Per-Client Source Scopes Policy Enforcement

/mcp/codex, /mcp/claude-code, and /mcp/other-local enforce independent toggle states and source allowlists; requests abort if policy changes mid-recall.

[mcp_servers.memocat]
url = "http://127.0.0.1:3792/mcp/codex"

Privacy & Boundaries

Local-Only Security Design & Known Scope

All parsing, indexing, and retrieval execute locally on your machine. Below are the implemented safeguards and current technical boundaries.

Zero Remote Servers or Telemetry

No user accounts, no cloud relay, and no analytics, crash reporting, or tracking SDKs (NSPrivacyTracking = false in the macOS privacy manifest).

Strict Loopback Validation

HTTP endpoints bind exclusively to 127.0.0.1 and validate Host, Origin, and Sec-Fetch-Site; extension sync checks the paired 32-char extension ID and 256-bit Bearer token.

Sandbox & Content Sanitization

Electron enforces contextIsolation and renderer sandbox; the extension applies script-src 'self' CSP; Markdown output is sanitized via DOMPurify.

Transparent Local Data Control

Local web mode defaults to ~/.memocat/<userId>/memo.sqlite (configurable via MEMO_DATA_DIR); desktop stores data under Electron userData for clean backup or deletion.

Current Technical Boundaries (v0.5.0)

  • Local memo.sqlite and exported JSON backups store plaintext conversation records without application-layer encryption; rely on macOS FileVault and file permissions.
  • The browser extension captures loaded visible DOM text only; it does not scrape private backend APIs for unexpanded history or auto-download remote images/media.
  • DMG and Mac App Store .pkg builds are generated via included build scripts (npm run build:dmg / npm run build:mas) and require Apple certificates for notarized/store distribution.
Get Started

Three Ways to Run MemoCat

Requires Node.js 24+ (for built-in node:sqlite). Run the macOS desktop app, the local web server, or the Chrome/Edge extension independently or together.

Option 01 · macOS Desktop App

Electron Desktop Workbench

Includes native macOS menu bar, view shortcuts (⌘1..5), background tray service on port 3792, and DMG / MAS bundle scripts.

git clone https://github.com/qiwihui/MemoCat.git
cd MemoCat
npm install
npm run desktop

Run npm run build:dmg to produce a local macOS disk image.

Option 02 · Local Web Mode

Node.js Built-in HTTP Server

The backend relies solely on Node.js built-in modules. Open http://127.0.0.1:3792 for full archive, recall, and MCP endpoints.

npm start
# Custom data directory & port
MEMO_DATA_DIR=/path/to/data PORT=3792 npm start

On macOS, you can also double-click Start MemoCat.command after cloning.

Option 03 · Chrome / Edge Extension

Load MV3 Extension

Build the extension package and load the unpacked output under Developer Mode in chrome://extensions.

npm run build:extension
# Load unpacked folder:
# dist/memocat-extension

Click "Connect & Sync" inside the extension to automatically pair with port 3792.
