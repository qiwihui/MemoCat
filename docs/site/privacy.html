MemoCat 隐私政策

生效日期：2026 年 11 月 20 日 · 适用产品：MemoCat 桌面端（com.qiwihui.memocat.desktop）及 Chrome 浏览器扩展（MemoCat · AI 对话归档）

核心承诺：MemoCat 采用纯本机离线架构。我们不设云端账号体系，不运营远程数据服务器，不收集、出售、共享或上传任何用户对话内容、目录路径或使用行为遥测。

1. 数据读取与本地存储

  • 用户主动授权的本机目录（桌面端）：桌面应用不会静默扫描未授权的系统目录。在 Mac App Store 沙盒环境下，仅当您通过原生文件选择器主动授予目录访问权限后，应用才以只读方式读取该目录中的 AI 工具本地日志（如 Codex、Claude Code、Grok Bot、Antigravity），并通过 macOS Security-Scoped Bookmark 在本机持久化保留该目录的只读授权。
  • 网页对话采集（浏览器扩展）：扩展仅在 manifest.json 明确列出的 AI 对话网页域名运行页面脚本，并在您点击保存或主动开启对应站点自动保存时，提取当前页面已加载的对话文本与标题，保存于浏览器本机 IndexedDB 与 chrome.storage.local。
  • 本机资料库存储：桌面端将导入并结构化后的对话正文、本地图片缓存、同步状态与召回取用记录保存在本机数据库（memo.sqlite）中。所有文件均留存在您的设备本地存储空间。

2. 本地网络回环与跨工具互通

  • 桌面端与浏览器扩展之间的增量同步、以及桌面端提供给本机 AI 客户端的 MCP 检索服务，仅监听本机回环地址 127.0.0.1（默认端口 3792），不会向互联网或局域网广播或发送任何数据。
  • 浏览器扩展与桌面端连接时校验 32 位扩展 ID 与本机生成并保存的 256 位随机配对密钥（Bearer Token）；所有跨 AI MCP 客户端的启用开关与可读取来源白名单均由用户独立控制。

3. 第三方追踪与广告

  • MemoCat 不包含任何第三方统计分析 SDK、崩溃上报 SDK、广告 SDK 或追踪域名（Mac App Store 隐私清单声明 NSPrivacyTracking = false，已收集数据类型为空）。
  • 扩展禁用远程脚本执行（CSP 严格限定 script-src 'self'），不会向任何外部模型训练服务、广告平台或数据经纪商传输您的数据。

4. 数据控制与删除

  • 您可以随时在浏览器扩展中删除单条对话或清空扩展本地资料库，并可导出标准 Markdown 或 JSON 备份。
  • 在桌面端，您可以随时关闭特定 AI 来源采集、撤销目录配置，或通过删除本机数据目录永久清除全部数据库及图片缓存文件。
  • 请注意：本地 memo.sqlite 数据库及导出的 JSON 备份文件以明文保存对话正文（未提供额外的应用层静态加密），请配合操作系统磁盘加密与系统账户权限妥善保管。

5. 联系方式

如对本隐私政策或商店审核事项有任何疑问，请在项目仓库 GitHub Issues 提交反馈，或参考 技术支持页面。
