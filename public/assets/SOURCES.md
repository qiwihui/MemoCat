# 图标与许可说明

- `memocat.svg`：MemoCat 原创矢量图标，以猫脸和对话气泡组合成轮廓。桌面端、网页工作台、站点和浏览器扩展的 PNG 与 `MemoCat.icns` 均由此图生成。
- `codex.png`、`claude-code.png`、`grok-bot.png`、`antigravity.png` 及 `platforms/*.png`：用于界面中识别各对应 AI 工具或网页对话平台来源。相关产品商标属于各自所有者，MemoCat 独立品牌图标不包含上述第三方品牌元素；来源图标仅作数据来源标识，不表示官方合作或背书。
- 界面内联设置的齿轮图标（`settings_3_line` / `settings_3_fill`）与刷新图标（`refresh_2_line`）取自 [MingCute Icon](https://github.com/Richard9394/MingCute)，遵循 Apache-2.0 开源许可证（完整许可证见 [MingCute-LICENSE.txt](MingCute-LICENSE.txt)）；内联 SVG 仅将填充/描边颜色调整为 `currentColor`。
